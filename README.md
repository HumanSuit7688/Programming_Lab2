# Лабораторная работа №2: одномерные статические массивы

Консольная программа на C++ для работы с целочисленным массивом размера `N = 100`.

## Возможности

- заполнение массива случайными числами из диапазона `[-99; 99]` или вручную;
- вывод массива;
- сортировки: пузырьковая, вставками, выбором, гномья и слиянием;
- замер времени сортировок через `std::chrono::steady_clock`;
- поиск минимума и максимума в исходном и отсортированном массивах;
- вычисление среднего значения min/max и поиск совпадающих элементов;
- подсчёт элементов меньше `A` и больше `B` через бинарный поиск границ;
- сравнение линейного и бинарного поиска;
- обмен элементов по индексам с замером времени;
- индивидуальное задание: подсчёт инверсий обычным перебором и Merge Sort.

## Работа с программой

После запуска выводится главное меню. Сначала выберите пункт `1` для случайного заполнения массива или пункт `2` для ручного ввода 100 чисел. После этого доступны остальные команды:

- `3` — вывести текущий массив;
- `4` — открыть меню сортировок;
- `5` — открыть меню поиска;
- `6` — обменять два элемента по индексам;
- `7` — выполнить индивидуальное задание;
- `0` — завершить программу.

В меню сортировок каждая сортировка запускается на копии исходного массива, поэтому исходный массив не изменяется. В меню поиска также создаётся отдельная отсортированная копия для операций, которым нужен упорядоченный массив.

## Структура проекта

Все исходные файлы находятся в корне проекта. Заголовки `.hpp` объявляют функции, а одноимённые `.cpp` содержат их реализацию.

| Файл | Назначение |
|---|---|
| `main.cpp` | Главный цикл, три меню, вызовы алгоритмов и замеры времени через `std::chrono` |
| `constants.hpp` | Общий размер статического массива `N = 100` |
| `array_utils.hpp/.cpp` | Случайное и ручное заполнение, вывод массива |
| `sorts.hpp/.cpp` | Четыре простые сортировки и сортировка слиянием |
| `search_operations.hpp/.cpp` | Min/max, среднее, подсчёт по границам, линейный и бинарный поиск |
| `individual_task.hpp/.cpp` | Подсчёт инверсий перебором и через сортировку слиянием |

`main.cpp` хранит исходный массив и обрабатывает команды. Алгоритмы вынесены в отдельные модули; для сортировки и поиска создаются копии исходного массива. После выхода из подменю снова показывается главное меню.

## Сборка

В VS Code достаточно нажать `F5`.

Или собрать из терминала:

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp array_utils.cpp sorts.cpp search_operations.cpp individual_task.cpp -o main.exe
```

Запуск:

```powershell
.\main.exe
```

## Пример замеров

Замеры получены на массиве из 100 элементов, расположенных в обратном порядке. Время зависит от компьютера, компилятора и режима сборки, поэтому значения приведены как пример.

| Bubble Sort | 20.50 |
| Insertion Sort | 14.80 |
| Selection Sort | 16.10 |
| Gnome Sort | 38.00 |

## Вывод

Простые сортировки имеют сложность `O(N²)`, а сортировка слиянием — `O(N log N)`, поэтому на тестовом массиве Merge Sort работает быстрее. Бинарный поиск требует отсортированный массив, но выполняется за `O(log N)` и в среднем быстрее линейного поиска `O(N)`. Для коротких операций применено усреднение времени по нескольким запускам.

## Индивидуальное задание

Инверсия — пара индексов `i < j`, для которой `arr[i] > arr[j]`.

Программа считает количество инверсий двумя способами:

- обычный перебор — `O(N²)`;
- модифицированная сортировка слиянием — `O(N log N)`.
